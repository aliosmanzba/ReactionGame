# Reaction Game

A simple reaction-time game built with Python and Tkinter. Wait for the target to turn green, then click it as quickly as possible.

## Features

- Random wait before the target turns green
- Detects early clicks
- Full-screen game window with an Escape key shortcut
- A reaction game with a fly that randomly moves around the screen.
- Wait for the fly to land on the food before trying to catch it.
- The fly is only hittable for a short 0.1–0.4 second window after landing.
- Reaction time is measured from the moment the fly lands until it is hit.
- A local Top 5 leaderboard keeps the fastest scores between sessions.
- A custom wooden-table theme with a plate, food, and a hand-shaped cursor.
- Background music and sound effects.
- Built with Python, Tkinter, and Pygame-CE.

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)
- Pygame-CE 2.5.8 or newer
